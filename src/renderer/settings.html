OpenPlead

Start here

  1. Adds a few hook entries to ~/.claude/settings.json, and to Cursor's hooks.json when Cursor is on. A .bak is kept. Nothing else changes.

  2. Click Grovel to plead. Once is polite, five times is a sob. The line reaches Claude with its next tool call, or with your next message if Claude is waiting for you.
  3. Right-click Grovel to thank, reassure, set a deadline, or read Claude's replies.

When is Grovel on screen?

Sound and chatter

Mute

Muted means no sounds and no chatter. Sent, dropped and replies still show.

Plead from the keyboard

Same as clicking Grovel.

Position

Drag Grovel anywhere. Drag him to a screen edge and he parks there, peeking out on hover.

Automatic messages

The lines Grovel uses

A random line from the set is used, never the same one twice in a row. Open a set to edit it, one line per row.

Advanced

The file is ~/.openplead/phrases.json; edits there apply at once.

Advanced

Hook entries live in ~/.claude/settings.json and ~/.cursor/hooks.json; a .bak is kept. Disconnect removes them.
