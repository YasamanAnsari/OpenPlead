# UX guidelines OpenPlead follows

The rules below come from the platform vendors and from published design research, not from taste. Each entry says
where the rule comes from and where OpenPlead applies it. When two platforms disagree, the app follows the platform it
is running on.

## Menu bar and notification area

| Rule                                                                                                                                                                                                           | Source                                                                                                                                                                          | Where                                                                                                                                     |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| On macOS the menu bar icon is a black-and-clear template image; the system tints it for light and dark bars. "Both interface icons and symbols use black and clear colors to define their shapes."             | [Apple HIG, The menu bar](https://developer.apple.com/design/human-interface-guidelines/the-menu-bar); [Electron Tray](https://www.electronjs.org/docs/latest/api/tray)         | `assets/tray/*Template.png` from `scripts/render-tray.js`; `src/desktop/tray.js` picks the family by platform                                        |
| State in a template icon is shown with opacity and alpha-only shapes; Apple uses about 35% opacity for disabled elements.                                                                                      | [Bjango, Designing macOS menu bar extras](https://bjango.com/articles/designingmenubarextras/)                                                                                  | Filled dot for "needs your OK", hollow ring for "queued", 50% while muted, 35% for "not connected"                                          |
| On Windows, status goes in a single overlay at the bottom-right; red, yellow and green are reserved for status; no long-running animation and no flashing in the notification area.                            | [Windows UX guide, Notification area](https://learn.microsoft.com/en-us/windows/win32/uxguide/winenv-notification)                                                              | Color icons with a bottom-right badge; the tray never animates                                                                           |
| The tooltip is "program – status", a sentence fragment that does not explain how to interact with the icon, within 127 characters.                                                                             | Same Windows UX guide; [NOTIFYICONDATA](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/ns-shellapi-notifyicondataa)                                               | `tooltipFor()` in `src/desktop/tray.js`                                                                                                           |
| A menu, not a popover, opens from the menu bar extra; the context menu ends with the quit command ("Exit" on Windows); state is shown with check marks, not by renaming items.                                  | Apple HIG above; Windows UX guide above                                                                                                                                         | `src/desktop/menu.js`                                                                                                                             |

## Menus

| Rule                                                                                                                                                                                                                | Source                                                                                                                                                                    | Where                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| macOS: title-style capitalization for menu items ("To be consistent with platform experiences, use title-style capitalization"). Windows: "Use sentence-style capitalization."                                      | [Apple HIG, Menus](https://developer.apple.com/design/human-interface-guidelines/menus); [Windows UX guide, Menus](https://learn.microsoft.com/en-us/windows/win32/uxguide/cmd-menus) | Labels are written in sentence style; `labelFor()` in `src/renderer/case.js` applies the platform's style |
| An ellipsis means more input is needed before the action completes. A submenu label never carries one.                                                                                                             | Both guides above                                                                                                                                                         | "More…" became groups with separators; "Reassure Claude" and "Set a deadline" are plain submenu labels     |
| Keep submenus to one level and about five items; group related items with separators; show unavailable items dimmed rather than hidden.                                                                            | Apple HIG, Menus                                                                                                                                                          | The hotkey submenu left the menu (it lives in Settings); "Cancel the next message" is dimmed while nothing waits |
| Context menus: at most 15 items, groups of seven or fewer, avoid submenus where possible; don't make commands available only through the context menu.                                                              | Windows UX guide, Menus                                                                                                                                                   | 11 commands in four groups and three short submenus; everything is also in the settings window                        |
| A menu item may carry a second, smaller line that explains it in place (macOS 14.4 and newer); elsewhere the label must stand alone. | [Electron `MenuItem.sublabel`](https://www.electronjs.org/docs/latest/api/menu-item) | `sub()` in `src/desktop/menu.js` adds it on macOS only; Windows and Linux fold the fact into the label and show two status lines |

## Settings window

| Rule                                                                                                                                   | Source                                                                                                | Where                                                                                       |
| -------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Dim the minimize and maximize buttons; the window fits the current pane.                                                               | [Apple HIG, Settings](https://developer.apple.com/design/human-interface-guidelines/settings)         | `src/desktop/settings-window.js`: fixed size, not minimizable or maximizable                        |
| "Update the window's title to reflect the currently visible pane." "Restore the most recently viewed pane."                            | Same                                                                                                  | `showTab()` in `src/renderer/settings.js`                                                   |
| Minimize the number of settings; give defaults that suit most people; keep rarely changed options in the settings area.                | Same                                                                                                  | One choice for when Grovel shows, a few switches, one hotkey, mute; sensible defaults           |
| Button labels: title-style capitalization on macOS, starting with a verb; a trailing ellipsis when the button opens another window or app. | [Apple HIG, Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)        | `caseButtons()` in `src/renderer/settings.js`; "Open the file…"                              |
| Checkbox titles sit on the trailing side; a label may describe the state the toggle controls.                                          | [Apple HIG, Toggles](https://developer.apple.com/design/human-interface-guidelines/toggles)           | Each toggle has a sentence-style title and a one-line hint                                   |

## Onboarding

| Rule                                                                                                                                                                                  | Source                                                                                              | Where                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| "Design a flow that's fast, fun, and optional." Prefer teaching through interaction: people retain more when they perform the task.                                                   | [Apple HIG, Onboarding](https://developer.apple.com/design/human-interface-guidelines/onboarding)   | The Welcome tab: three two-line steps, Done at any time, "Show me (20 s)"   |
| "If you let people skip the tutorial when they first launch your app, don't present it again … but make sure it's easy for people to find if they want to view it later."           | Same                                                                                                | The Welcome tab hides after Done and reopens from About                      |
| "Consider providing a collection of context-specific tips instead of a single onboarding flow." Show instructions near the area they refer to.                                       | Same                                                                                                | The once-only coaching lines in the pet's bubble, at the moment they apply   |
| "Postpone nonessential setup flows"; "Provide reasonable default settings."                                                                                                           | Same                                                                                                | Connect is the only setup step; everything else has a default               |

## Motion and feedback

| Rule                                                                                                                                                                                        | Source                                                                                                        | Where                                                                                           |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| "Don't add motion for the sake of adding motion"; "aim for brevity and precision in feedback animations"; "avoid adding motion to UI interactions that occur frequently"; make motion optional. | [Apple HIG, Motion](https://developer.apple.com/design/human-interface-guidelines/motion)                 | The queued chip settles once (300 ms) and then holds still; everything stops under Reduce Motion |
| Most UI animations belong between 100 and 500 ms; the more often people see one, the shorter and subtler it should be.                                                                      | [NN/g, Animation duration](https://www.nngroup.com/articles/animation-duration/)                              | 150 ms bubble fade, 300 ms chip entrance                                                        |
| An indicator sits next to the element it describes, is passive, and changes only when the state does: "if something always looks the same, it's not an indicator."                          | [NN/g, Indicators, validations and notifications](https://www.nngroup.com/articles/indicators-validations-notifications/) | The nameplate under the pet; the tray badge                                           |
| Quick-fading messages go unnoticed; toasts need a few seconds at least (Carbon: five by default; Dialpad: at least six, more for people reading in a second language).                       | NN/g above; [Carbon, Notification](https://carbondesignsystem.com/components/notification/usage/); [Dialpad, Toast](https://dialtone.dialpad.com/components/toast.html) | `readingMs()` in `src/desktop/bubbles.js`: four to ten seconds, by word count |

## Writing

| Rule                                                                                                                                      | Source                                                                                          | Where                                                                             |
| ----------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| "Be clear … If you can use fewer words, do so." "Prioritize clarity and avoid the temptation to be too cute or clever with your labels." | [Apple HIG, Writing](https://developer.apple.com/design/human-interface-guidelines/writing)     | Labels, hints and coaching lines; Grovel's own lines are the product and stay funny |
| "Make it clear when a flow is complete by using language like 'Done.'"                                                                   | Same                                                                                            | The Welcome tab ends with Done                                                    |
| Pick a capitalization style per element type and apply it consistently.                                                                  | Same                                                                                            | Title style for buttons and menu items on macOS, sentence style for toggles and hints everywhere |

## Accessibility

| Rule                                                                                                                                                                          | Source                                                                                                                    | Where                                                                                                                                  |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Text has a contrast ratio of at least 4.5:1 (3:1 for large text); inactive controls are exempt.                                                                               | [WCAG 2.2, 1.4.3 Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)                   | Nameplate text 13:1, muted 4.7:1 on a mid-grey desktop; settings muted 5.3:1; the primary button's dark label 4.9:1 on orange          |
| Parts of a graphic or control that carry meaning, and focus indicators, reach 3:1 against adjacent colors.                                                                   | [WCAG 2.2, 1.4.11 Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)                  | Lit ladder dots 3.1:1, unlit 3.5:1; status dots 3.2:1 or better; focus ring 4.7:1 light, 5.5:1 dark                                     |
| Tabs: `tablist`/`tab`/`tabpanel` roles, `aria-selected`, one tab stop with arrow keys moving between tabs and wrapping, Home/End, automatic activation when panes have no latency. | [WAI-ARIA APG, Tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)                                            | The settings window's panes                                                                                                            |
| Standard shortcuts keep their meaning: Command-W closes the window, Command-Q quits, Command-Comma opens settings.                                                             | [Apple HIG, Keyboards](https://developer.apple.com/design/human-interface-guidelines/keyboards)                            | Electron's default application menu supplies the Edit and Window roles; nothing overrides them                                         |
| Motion is optional: everything that moves stops under Reduce Motion.                                                                                                          | Apple HIG, Motion (above)                                                                                                 | `prefers-reduced-motion` rules in the pet window                                                                                      |

## Companion behavior

| Rule                                                                                                                                                        | Source                                                                                                                                                                                                                 | Where                                                                                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Calm technology: attention stays in the periphery and moves to the center only when needed; require the smallest possible amount of attention.             | [Weiser and Brown, Designing Calm Technology](https://en.wikipedia.org/wiki/Calm_technology); [Calm Tech Institute, principles](https://calmtech.institute/calm-tech-principles)                                        | Grovel shows only while a session is alive and the agent's app is in front, sleeps when idle, parks at the edge; the tray badge carries state while hidden |
| Proactive help has to earn its interruptions; help on demand, not forced; never optimize only for first use.                                                | Retrospectives on the Office Assistant: [SAS](https://blogs.sas.com/content/sgf/2019/05/29/what-can-we-learn-from-clippy-about-ai/), [Command AI](https://command.ai/blog/what-clippy-taught-us-all)                   | No unprompted pop-ups; each coaching line shows once, at the moment it applies; the demo and walkthrough are on demand; Mute silences chatter            |
| A click on a menu bar extra opens its menu; the notification area shows status, not instructions.                                                            | Apple HIG, The menu bar; Windows UX guide, Notification area (above)                                                                                                                                                   | Left-click opens the menu on macOS; on Windows it shows the pet                                                                                          |

## Glossary

One term per thing, used the same way everywhere (Apple HIG, Writing: "create a list of common terms").

| Term            | Meaning                                                                                      |
| --------------- | -------------------------------------------------------------------------------------------- |
| Grovel           | The pet. Never "the assistant" or "the agent".                                               |
| the agent       | Claude Code or Cursor, named when known ("Claude Code · working").                           |
| plea, plead     | A line queued by a click, levels 1 to 5 ("Plea 2 of 5"); the verb for the action.           |
| thank-you       | The line queued for the next message after a finished turn.                                  |
| calm line       | What goes out instead of a plea after two failures in a row.                                 |
| queued, sent, dropped | The three outcomes of a line, as the chip and the bubble say them.                     |
| nameplate, chip | The HUD under Grovel; the chip is its second line with the outcome.                           |
| Connect, Disconnect | Writing or removing the hook entries. Never "install hooks" in the UI.                 |
| Mute            | No sounds and no chatter; outcomes still shown.                                              |
| Park            | Mini mode: Grovel at a screen edge with a sliver showing.                                     |
| session, turn   | An agent session (from start to end) and one prompt-to-answer turn within it.                |
